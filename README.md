# Q-Paste

> 一款极简、高效的 Windows 桌面剪贴板管理工具，助你告别繁杂的复制粘贴。

![Version](https://img.shields.io/badge/version-1.3.1-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-windows-blue)

Q-Paste 静默运行于系统托盘，自动捕获你复制过的文本、链接、图片、富文本与文件列表，随时通过全局快捷键唤出取用。数据默认全部保存在本地，安全可控；还可通过 WebDAV 在多台设备间云同步，或扫码与手机在局域网内互传文件。

---

## ✨ 功能特性

### 📋 捕获与取用
- **多格式捕获**：纯文本、链接（URL）、图片（≤ 10 MB）、富文本（HTML，保留格式）、文件列表自动入库
- **全局唤醒**：默认 `Alt+Space` 一键呼出/隐藏窗口，不打断当前工作流（快捷键可自定义）
- **快速取用**：选中即复制；URL 可一键在浏览器打开，文件可一键重新打开
- **全文搜索**：基于数据库的全文检索，历史与金库均可搜索（匹配内容、预览、别名与标签）
- **标签过滤**：点击标签 chip 快速筛选历史与收藏
- **重复内容去重**：复制相同内容自动复用原记录并置顶，历史列表不堆积冗余（可在设置中关闭）
- **拖拽自定义排序**：鼠标按住历史列表中的条目上下拖拽即可重排，顺序立即保存；日常按复制时间倒序，最新记录始终在顶部
- **二维码分享**：文本 / 链接一键生成二维码，手机扫码即取
- **OCR 文字提取**：图片中的文字一键识别（中英文），识别结果自动入库
- **保存为文件**：剪贴板文本一键另存为文件

### 📱 局域网文件传输
- **扫码即传**：手机扫描二维码直连电脑，互传文件、图片、视频与文本消息，无需数据线、不走公网
- **聊天式体验**：电脑与手机端均为聊天式界面，像发消息一样传文件
- **稳定传输**：分块上传 + 断点续传，大文件也可靠
- **安全省心**：仅局域网内可访问；空闲自动关闭服务，端口、保存路径、接收后自动打开/复制均可配置

### ☁️ 云同步（WebDAV）
- **多设备同步**：通过 WebDAV 在多台设备间同步剪贴板历史（坚果云、Alist、Nextcloud 等均支持）
- **全量上云**：首次开启自动迁移全部存量历史（400 条/批），云端快照备份可随时导入恢复
- **可靠写入**：临时写入 + 多重校验 + 原子转正，同步中断不损坏数据
- **灵活配置**：自动同步间隔可调，实时显示同步状态与收发统计

### 🗂️ 金库管理
- **收藏常驻**：一键收藏重要内容，金库中的记录**永不被自动清理**
- **拖拽自定义排序**：鼠标按住金库条目上下拖拽即可重排，顺序立即保存；默认按收藏时间倒序排列，后收藏的永远在最上面
- **分类标签**：为记录添加标签，金库按标签自动分组，快速定位
- **自定义别名**：为常用内容设置别名，替代冗长的原文预览
- **防误删保护**：删除收藏内容需二次确认

### 🔒 安全与隐私
- **本地存储**：所有数据保存在本地，无需联网，断网可用
- **敏感数据检测**：自动识别身份证号、手机号、API Key、JWT、银行卡、私钥等敏感信息并标记
- **脱敏显示**：敏感内容默认遮蔽显示（如 `138****1234`），点击方可查看
- **忽略规则**：支持正则黑名单，命中规则的内容（如密码管理器复制的密码）不会被捕获

### 🧹 数据管理
- **图片落盘存储**：图片以文件形式保存在磁盘，数据库保持轻量，不随截图无限膨胀（旧数据自动迁移）
- **大文本落盘**：超大文本自动落盘保存，库内只存引用，写入失败自动重试并排队补录，**记录永不静默丢失**
- **超大内容确认**：超过上限的内容弹窗确认「完整保留 / 截断」，绝不悄悄丢弃
- **数据库自愈**：数据库异常时恢复扫描择优修复，存储管理中可一键校验完整性
- **保留策略**：可设置记录保留时间（7/30/90 天/永久）与最大条数（默认 500），自动清理旧记录，金库数据不受影响
- **备份 / 导入导出**：一键备份数据库文件（.db，含全部记录与图片）；支持 JSON 导出与**导入**，换机迁移一键闭环
- **空间释放**：一键清除未收藏的图片缓存或全部历史记录
- **自定义存储路径**：支持将数据迁移到任意目录，图片随之完整迁移

### ⌨️ 快捷键自定义
- **本地快捷键可配置**：复制、删除、收藏、导航、清空搜索均支持自定义组合键
- **冲突检测**：同一按键被多个功能占用时自动拦截提示
- **一键恢复默认**：随时还原初始键位

### 🎨 个性化
- **多语言**：简体中文 / English
- **主题模式**：浅色 / 深色 / 跟随系统
- **强调色**：6 种主题色自由切换
- **界面密度**：宽松 / 紧凑列表布局
- **宽度随心调**：拖拽列表栏与详情栏之间的分隔条即可调整左右宽度，调整结果自动记忆
- **等宽字体**：代码片段使用 Monospace 增强可读性

### 🖥️ 系统集成
- **系统托盘**：显示窗口、打开设置、暂停/恢复监听、退出
- **开机自启**：可选随系统启动并最小化到托盘（启动行为可配置）
- **沉浸窗口**：真实透明标题栏 + 自绘窗口按钮 + 窗口圆角，二次启动自动唤出
- **单实例**：重复启动自动唤起已有窗口
- **自动更新**：新版本自动发现、下载、重启安装（设置页可手动检查）

## 🚀 快速开始

1. **启动**：打开 Q-Paste，程序静默运行于系统托盘，自动开始监听剪贴板。
2. **呼出**：按下全局快捷键 `Alt+Space`，唤出剪贴板历史窗口。
3. **取用**：点击列表项，或使用 `W` / `S` 键上下切换、`Enter` 确认复制，内容即写入系统剪贴板，直接 `Ctrl+V` 粘贴即可。
4. **收藏**：对重要内容按下 `Ctrl+P`（或点击「收藏」按钮），存入金库长期保留。
5. **互传**（可选）：在设置中开启「局域网文件传输」，手机扫码即可与电脑互传文件；需要多台电脑同步历史时，开启「云同步」并填入 WebDAV 账号即可。

> 💡 小技巧：在设置中开启「复制后自动隐藏窗口」，复制完成后窗口自动收起，弹窗式体验更顺手。
>
> 💡 拖拽排序：在历史或金库列表中，鼠标按住条目上下拖拽即可自定义顺序（拖拽结果立即保存）。仅在未搜索、未标签过滤时可用——此时显示的是完整列表，安全拖拽。

## ⌨️ 快捷键一览

> 以下为默认值，均可在 **设置 → 快捷键** 中自定义（含冲突检测与一键还原）。

| 快捷键 | 功能 |
| --- | --- |
| `Alt+Space` | 全局：呼出 / 隐藏窗口 |
| `W` / `S` | 上一条 / 下一条记录 |
| `Enter` / `C` | 复制选中内容 |
| `D` / `Backspace` | 删除选中记录（收藏项需二次确认） |
| `Ctrl+P` / `Alt+P` | 收藏 / 取消收藏 |
| `Esc` | 清空搜索 → 取消选中 |

## 🗂️ 数据与隐私

- 所有剪贴板历史、图片与设置默认保存在**本地**，不做任何上传。
- 云同步与局域网传输均为**可选功能**，仅在你主动开启后才会传输数据：云同步走你自己的 WebDAV 账号（凭据仅保存在本机），局域网传输仅在局域网内、不经过公网。
- 默认存储位置：系统用户数据目录下（`q-paste.db` 与 `images/` 目录，可在设置中更改）。
- 敏感内容仅作标记与脱敏显示，不会做任何网络传输。
- 建议定期使用「备份数据库文件」功能备份数据，或开启云同步获得云端快照。

## 💻 本地开发

```bash
# 安装依赖
npm install

# 开发模式（热更新 + 自动启动 Electron）
npm run dev

# 类型检查
npx tsc --noEmit

# 构建（当前平台）
npm run build

# 构建 Windows 安装包
npm run build:win

# 发布 GitHub Release（需配置 GH_TOKEN）
npx electron-builder --publish always
```

构建产物输出到 `release/` 目录。

### 项目结构

```
q-paste/
├── electron/              # 主进程与 preload（剪贴板监听、数据库、托盘、快捷键、自动更新）
│   ├── main.ts
│   ├── preload.ts
│   └── file-transfer/     # 局域网文件传输服务（HTTP + WebSocket、手机端页面）
├── src/                   # 渲染进程（React）
│   ├── components/        # UI 组件（Sidebar / DetailView / Settings / FileTransferChat 等）
│   ├── main/sync/         # WebDAV 云同步引擎（SyncEngine / WebDavService）
│   ├── lib/               # 工具函数（敏感检测、快捷键、格式化等）
│   ├── i18n.ts            # 中英文文案
│   └── types.ts           # 类型定义
├── tests/                 # Vitest 回归测试
├── build/                 # 图标等打包资源
└── release/               # 打包产物
```
