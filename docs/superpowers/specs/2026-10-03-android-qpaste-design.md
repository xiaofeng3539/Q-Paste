# Q-Paste Android 第一版设计

日期：2026-10-03
状态：设计待用户审阅，尚未开始产品实现。

## 1. 已确认的目标

开发 Android 手机端 Q-Paste，采用 Kotlin 和 Jetpack Compose，通过电脑端现有 WebDAV 云同步交换剪贴板内容。

第一版采用手动收集：用户从其他应用分享内容到 Q-Paste，或在应用内点击“粘贴保存”。手机可以查看、复制和分享电脑同步过来的内容。内容先在本地保存，网络失败不影响使用。

本次范围不包含花笺笔记、后台自动捕获剪贴板、局域网文件传输、OCR、悬浮窗和 iOS 客户端。同步账号由用户填写，不提供账号服务。

## 2. 用户流程与界面

### 历史页

- 按时间倒序显示内容，提供搜索和全部、文本、链接、图片、富文本筛选。
- 点击记录查看详情；支持复制、系统分享和本地删除。
- 文本和链接直接复制；图片通过 FileProvider 提供内容 URI；富文本保留纯文本和 HTML，显示时禁用脚本和网络资源加载。
- 顶部显示同步状态，提供手动刷新；没有记录时显示导入入口。
- 不设置收藏入口，避免第一版增加尚未定义的收藏同步语义。

### 收集入口

- 接收 ACTION_SEND 的文本、HTML 和图片，以及 ACTION_SEND_MULTIPLE 的图片。
- 分享后进入导入确认页，预览内容；点击保存后才写入本地并加入待同步队列。
- “粘贴保存”由用户主动触发，仅在前台读取剪贴板。
- 图片从临时授权的内容 URI 复制到应用私有目录，不依赖授权长期有效。
- 同内容重复导入复用原记录，不新增重复列表项；手动再次保存已删除内容可恢复该记录。
- 文件及不支持的 MIME 类型提示不支持，不作为空内容导入。

### WebDAV 设置页

- 设置服务器地址、用户名、密码和同步目录；目录默认 qpaste-sync。
- 提供连接测试、启用开关、立即同步和上次同步结果。
- 默认关闭云同步，用户完成配置并启用后才访问服务器。
- 修改服务器、账号或目录时创建新的同步空间状态，避免复用上一空间的游标和上传标记；已有本地内容保留。

## 3. 技术结构

在仓库新增独立 mobile/android 项目，不将 Electron 主进程代码直接引入 Android，不修改电脑端已有界面和打包配置。

采用单个 Android 应用模块，按 ui、data、sync 划分代码职责。使用 Jetpack Compose、ViewModel、Room、Kotlin Coroutines、OkHttp 和 WorkManager。通过原生 Intent、ClipboardManager 和 FileProvider 实现导入、复制及分享。不添加跨平台抽象和多模块框架。

最低支持 Android 10（API 29）。编译和目标 SDK 使用实施时核实的稳定版本并固定版本；不使用动态依赖版本。应用显示名称为 Q-Paste，applicationId 为 com.qpaste.mobile。

本地数据库保存完整记录、上传队列、同步游标及序号。图片正文存在私有文件，数据库保留路径和元数据。系统备份排除凭据和同步设备状态，避免两台设备继承同一 deviceId。

## 4. 与电脑端兼容的同步协议

依据 src/main/sync/types.ts、SyncEngine.ts 和 electron/main.ts 的现有行为实现兼容客户端。

| 内容 | 约定 |
| --- | --- |
| 远端根目录 | 用户配置的 basePath，默认 qpaste-sync |
| 增量文件 | ops/{deviceId}__{20 位补零序号}.json |
| 批次字段 | deviceId、seq、uploadedAt、entries |
| 条目字段 | deviceId、type、content、html、contentBlobHash、htmlBlobHash、hash、preview、createdAt、updatedAt、deletedAt |
| 类型 | text、link、image、rich_text |
| 时间 | Unix 毫秒时间戳 |
| 内容指纹 | UTF-8 字符串 SHA-256，十六进制小写 |
| 图片格式 | 完整 data URL；图片内容指纹针对完整 data URL 计算 |
| 大文本阈值 | 超过 12 KiB 使用 blob |
| 大 HTML 阈值 | 超过 24 KiB 使用 blob |
| 图片限制 | 解码后最多 8 MiB，超过时拒绝导入并说明原因 |
| blob 路径 | blobs/{hash 前两位}/{image、content 或 html}_{hash}.blob |

富文本保存纯文本 content 和 HTML html。新建记录对 content 计算指纹；拉取时保留远端提供的 hash，不改写旧数据。测试覆盖电脑单条上传和全量上传两种现有格式，手机按类型与实际内容识别重复记录。

WebDAV 使用 Basic Auth、PROPFIND、MKCOL、GET、HEAD、PUT、MOVE 和 DELETE。路径逐段编码，支持中文和空格。上传先 PUT 临时文件，再 MOVE 发布；按电脑现有行为对不支持 MOVE 的服务器回退到直接 PUT。手机仅清理自身未发布的临时上传文件，不删除其他设备数据。

手机生成独立 deviceId；上传序号持久化。每个同步空间的上传串行执行，成功发布后再确认本地队列。网络失败使用同一序号重试，防止序号冲突或跳过待上传内容。

拉取以每台远端设备的 seq 游标为准，不使用本机时间过滤未读批次。一个批次的内容、blob 和数据库事务全部成功后才推进游标；批次损坏或 blob 缺失时保留游标并显示错误，不跳过失败批次继续推进该设备游标。

不覆盖 backup/qpaste-backup.json，该文件属于电脑端数据库快照，不用于手机增量同步。

## 5. 同步触发、合并与删除范围

- 打开应用、导入保存后及手动刷新时发起同步；同一时间只运行一轮。
- 每轮先拉取远端，再发送本地待上传项。启用同步时将尚未上传的本地存量加入队列。
- 应用处于前台时每 120 秒尝试同步。退到后台后取消前台定时器。
- 未发送完成的队列通过有网络约束的 WorkManager 重试；后台执行时间由系统调度，不承诺实时同步或后台轮询拉取。
- 同一条目的变更按 updatedAt 比较，较新的版本优先；相同时间且正文不同的异常记录保留本地版本并显示同步异常。
- 删除仅影响当前设备，不上传删除墓碑。保留本地隐藏标记，重复拉取同一记录不能使其重新出现；用户主动重新导入可以恢复。
- 电脑当前忽略 deletedAt > 0 的条目。手机第一版同样不应用远端墓碑，也不提供跨设备删除选项。
- 电脑既有同步实现的问题不在本次任务中顺带修复；若互通验收发现必须修复的电脑问题，先报告实际证据和最小修改范围。

## 6. 安全与错误处理

- WebDAV 密码由 Android Keystore 生成的密钥加密后保存在应用私有存储，不进入日志、数据库导出或系统备份。
- HTTPS 使用正常证书校验，不允许跳过校验。用户显式填写 HTTP 地址时，设置页提示传输未加密后再启用；不会自动把 HTTPS 降为 HTTP。
- 401/403 显示鉴权错误；网络超时、无法连接、服务器异常分别显示可理解的结果。
- 网络失败保留本地内容和上传队列；自动重试有上限并退避，手动刷新可以重新尝试。
- blob 下载设置大小限制，不接受超出协议限制的图片；预览不执行远端 HTML 脚本。
- 下载失败、空间不足或临时 URI 无权限时提示错误，不保存无法读取的图片记录。
- 设置修改和关闭同步后，旧请求不得写入新同步空间的状态。

## 7. 验收与交付

### 自动验证

- 使用固定协议样例和本地 WebDAV 模拟服务验证 Android 上传格式与电脑引擎一致。
- 验证电脑上传、手机拉取，以及手机上传、电脑拉取，覆盖文本、链接、图片、富文本和大内容 blob。
- 验证重复同步、离线队列、进程重启、上传中断、缺失 blob、鉴权失败和切换同步空间。
- 验证同一手机并发触发同步不会重复发布或覆盖序号；数据库成功写入前不推进拉取游标。
- 验证本地删除不影响电脑，也不会因刷新恢复已隐藏的记录。
- 运行 Android 单元测试和静态检查；不改电脑可执行代码时无需重新打包电脑端。

### 设备验证

- 验证冷启动和已运行时的分享导入、前台粘贴、图片复制与分享、旋转屏幕和中文搜索。
- 使用测试 WebDAV 空间互传两端内容，确认断网恢复后队列仍可发送。
- 不读取用户真实 WebDAV 凭据；真实账号测试需要用户提供测试环境或自行完成。
- 若没有模拟器或真机，明确报告设备验证未完成，不把编译通过描述为完整功能验收。

### 构建交付

- 补齐 Java、Android SDK 和 Gradle 构建环境后执行 Release 编译与完整 APK 打包。
- 开发验证可使用 debug APK；正式 Release APK 必须使用正式签名。没有用户签名材料时报告签名阻塞，不用调试签名冒充正式交付。
- 检查 APK 的应用标识、版本、架构及资源，报告完整产物路径。
- 第一版手机版本号从 0.1.0 开始，与电脑 v1.4.0 分开管理。
- 不自动上传 GitHub、不发布 tag 或应用商店。
